# 控制面板重设计

2026-10-26，v0.12.0。采用暖白底色、深绿色重点按钮、轻边框与圆角，统一标题、说明、字段和按钮的间距。面板使用 WPF 原生控件及局部样式，没有新增运行时依赖。

## 操作方式

- 左侧导航分为晾衣绳列表、本地历史、来源与设置、快捷键与启动、外观与语言、格式支持。顶部保留显示/收起和导入两个常用入口。
- 晾衣绳列表突出文件名，路径过长时省略，悬停可查看完整路径。没有内容时显示空状态和导入按钮。复制、预览和图片编辑直接可见；导出、定位、取下等放在“更多操作”。视频不提供编辑入口。
- 本地历史支持按文件名或路径搜索，并保留重新挂上、预览、导出和文件管理。搜索只过滤显示，不改动记录或文件。
- 设置按用途分卡片；额外目录及快捷键高级说明可展开。三个设置页共享底部保存栏，修改后显示“有未保存的更改”，支持跨页填写、统一保存或撤销。保存失败保留草稿，撤销后清除错误提示。收起控制面板保留草稿；退出程序后未保存草稿不保留。
- 左侧持续显示自动收集状态，暂停/恢复立即生效，保留正在填写的设置。
- 窗口默认 1060×780，最小 840×620；窄窗口缩小导航宽度，设置内容独立滚动，保存栏固定在底部。保留原有键盘浏览、Tab 焦点和控件无障碍名称。高对比度模式在创建面板时使用系统颜色。

快捷键、截图和录像收集、历史保留、文件复制与回收规则不变，不迁移数据库。原有用户设置继续读取。视频仅用于挂绳、只读播放及完整原文件操作；图片编辑保留。
