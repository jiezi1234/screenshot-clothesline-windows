# 晾衣绳整排同时入场

v0.18.3，2026-10-30。

按 Ctrl+↓ 或悬停展开时，绳线与当前页的图片、录像、文字卡片先完成窗口、显示器 DPI、位置和内容布局准备，再一起显示。新显示的窗口在准备阶段保持完全透明；全部就绪后使用同一个约 180 ms 淡入时钟，从而消除逐张准备窗口带来的先后入场。

原有卡片轻微缩放和摆动继续保留，约 620 ms 内停稳。鼠标进入或开始操作时仍会立即停稳。开启“减少动画”或关闭 Windows 客户端动画后，整排准备完毕即直接显示，不启动淡入或摆动。

已经展开时新增内容，仅进入当前页的新窗口播放入场；已有卡片不会重新淡入。空绳提示也使用统一的准备与显示流程。收起、快速反复展开、关闭程序时解除时钟和完成事件；单张卡片停止动画不影响其他卡片。准备失败时收起本批尚未显示的窗口，避免留下不可见的交互窗口。

缩略图与文字文件的异步读取沿用现有逻辑；本次统一的是窗口布局与入场时机，不新增阻塞式文件读取或新依赖。图片始终在文字左侧，四种纸张、堆叠、拖放、悬停编辑和 0.6 秒自动保存规则保留。
