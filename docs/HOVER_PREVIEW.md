# 图片悬停放大预览

v0.14.0，2026-10-28。独立实现，不参考已有 Windows 移植项目。

## 使用

v0.15.0 增加[堆叠时先突出绳上卡片](STACKED_SHELF.md)，继续悬停后按以下规则显示完整大图。

- 展开晾衣绳，鼠标停在图片卡片约 400 ms 后显示放大图；随 100 ms 输入检查周期，实际触发可能稍晚。
- 保持原图比例、显示完整图片，不按卡片缩略图区域裁切。图片展示区最大约 640 × 480 DIP，并随显示器缩放调整。
- 优先放在右侧，右侧不够则尝试左侧；左右会挡住其他卡片时放在整行下方，并按可用空间缩小。极小工作区没有安全位置时不弹出。
- 移开鼠标、点击、右键、开始拖动、翻页、改变布局、收起晾衣绳或锁屏时取消预览。Esc 可收起；离开后重新悬停可再次显示。
- 浮窗不抢键盘焦点，鼠标事件穿透到下方窗口；浮窗自身不会延长悬停，也不会遮住晾衣绳卡片。
- “减少动画”或系统关闭动画时，继续显示预览，但停用出现动画。录像卡片继续使用既有播放入口，不触发图片放大。

首次先展示已有缩略图，再异步换成更清晰的预览。暂存文件已移走或解码失败时会收起浮窗，文件和晾衣绳记录不受影响。此功能不增加新的快捷键和设置，不修改原文件。

## 实现与资源

输入检查复用晾衣绳现有定时器，并通过 `WindowFromPoint` 确认真正位于鼠标下方的卡片；被其他窗口遮挡的卡片不会触发。鼠标离开和按下事件立即收起预览，异步任务用取消令牌与请求编号阻止旧结果重新弹出或串图。

放大图沿用隔离解码工作进程，新增 `preview` 模式：在工作进程中缩到长边最多 1600 像素后交付主进程，交付前仍校验尺寸、长度和文件签名。最多保留当前浮窗的一张放大图，收起后解除图像引用，不加入 64 项缩略图缓存。原有双工作进程并发、20 秒超时、源图片大小/像素限制和取消清理继续生效。

透明浮层使用 `NOACTIVATE`、`TOOLWINDOW` 与 `WS_EX_TRANSPARENT`，复用原有多桌面与屏幕布局机制。无新增依赖或数据库迁移，继续使用 v3 库。

参考：[Microsoft Window.ShowActivated](https://learn.microsoft.com/dotnet/api/system.windows.window.showactivated)、[Microsoft layered window hit testing](https://github.com/MicrosoftDocs/win32/blob/docs/desktop-src/winmsg/window-features.md)。

## 人工核验

- [ ] 鼠标快速扫过不弹出，停留后显示完整图；在相邻图片间切换时内容正确。
- [ ] 单击复制、双击打开、长按、右键、取下和拖动排序仍正常；开始拖动时预览立即消失。
- [ ] 屏幕两侧、满行、末页、竖图和超宽图预览不越界、不挡住卡片。
- [ ] 混合 DPI、多显示器、拔插/锁屏/虚拟桌面切换后，没有残留浮窗或位置错误。
- [ ] 减少动画生效；慢文件、损坏文件、文件正在更新时，界面保持可用，浮窗不显示过期结果。
