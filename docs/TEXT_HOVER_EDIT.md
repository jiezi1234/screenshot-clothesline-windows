# 在悬停预览中编辑文字

v0.18.2，2026-10-30。

1. 悬停文字卡片约 400 ms，出现沿用纸张样式的全文浮层。浮层直接可编辑，不需要先点击“编辑文字”；点击文字定位光标即可输入。仅悬停不会抢走其他应用的键盘焦点。
2. 可以用鼠标拖选部分文字，再按 Ctrl+C 或右键“复制”。只复制选中的部分，保留 Unicode、空格与换行；复制带自身标记，避免重新收集成新卡片。单击绳上卡片仍复制全文。
3. 修改后停止输入约 600 ms 即自动保存到原卡片，无需移开鼠标或点击保存。连续输入重新计时，保存期间可继续编辑；后续内容会按顺序保存。输入法组词期间暂缓保存，确认文字后继续。鼠标离开卡片和浮层时会保存最新修改并关闭。穿过二者之间的空隙保留 450 ms 宽限；拖选文字、拖动滚动条、使用右键复制菜单期间保持浮层。保存过程中鼠标返回浮层，会继续保留编辑界面。
4. 保存失败时保留浮层、错误提示和草稿，不反复自动重试。再次修改后会自动重试，也可点击“保存文字”或按 Ctrl+S。保存成功保持原卡片身份、纸张、排序与加入时间，随后刷新内容、标题和缩略图。
5. Esc、Alt+F4 会尝试保存并关闭；失败仍保留草稿。“取消编辑”只放弃上次保存之后尚未保存的修改并关闭；已经自动保存的内容可以通过撤销再修改。Ctrl+S 可以提前保存，保存后仍可在浮层继续修改。

Ctrl+↑ 收起、锁屏或显示器变化会隐藏浮层；已有未保存草稿继续等待自动保存，成功后释放浮层与文件保护；失败的草稿仍在本次运行中保留，再次显示晾衣绳时恢复。没有修改的预览直接释放。程序退出时若仍有未保存修改，沿用默认保留草稿的放弃确认。关闭后，若键盘焦点仍在浮层内，会归还给之前的窗口；用户已切换到其他应用时不干扰其焦点。

阅读或编辑浮层期间延后晾衣绳刷新。没有修改时，点击卡片、排序或翻页可以直接关闭预览并继续操作；尚有修改时先完成保存。后台收集继续，浮层关闭后显示新增卡片。双击和历史中的独立编辑器入口保留；同一文字已在独立编辑器打开时，悬停只预览，双击回到现有编辑器，避免两个编辑器互相覆盖。

复用原有文字保存事务、校验、配额、冲突检查与文件使用保护。文件被外部修改、锁定、内容无效或保存失败时保留草稿与原文件，不自动覆盖外部修改。没有新增数据库迁移或运行时依赖。草稿仅在本次运行中保留，不提供断电或强制结束进程后的未保存草稿恢复。
