# 在悬停浮层中编辑图片

v0.21.2，2026-10-30。

悬停图片约 400 ms，先显示缩略图，原图加载完成后在同一个浮层显示工具栏。无需另外打开编辑窗口；悬停本身不会抢走当前应用的键盘焦点，点击工具或画布后可交互。

v0.21.2 使用“轻盈工具条”：浅色圆角面板，顶部左侧显示文件名、右侧上一步／下一步；七种工具保持单排，当前工具以浅绿色和描边标识。下方按工具显示颜色、粗细、字号、文字输入或马赛克大小，浏览和裁剪只显示操作提示。底部显示自动保存状态、图片尺寸与缩放选项。窄空间自动收起文字标签，保留图标、悬停提示、键盘焦点与无障碍名称。缩放菜单打开时保持浮层，收起晾衣绳会同步关闭菜单。沿用系统高对比度色板，没有增加字体、图标包或运行时依赖。

- 工具包括浏览、裁剪、画笔、箭头、矩形、文字、马赛克。文字工具先填写内容，再点击画布放置。颜色与笔画粗细可调整。
- “上一步”撤销，“下一步”恢复，快捷键为 Ctrl+Z / Ctrl+Y。自动保存和关闭浮层均不会清空最近图片的撤销历史，再次悬停同一张图片仍可继续上一步／下一步；切换其他图片再返回也会恢复各自状态。撤销后新增修改会清空恢复分支。
- 完成修改约 600 ms 后自动保存；绘制中的笔画或马赛克处理不会被中断。保存期间仍能继续编辑，后续修改按顺序保存。Ctrl+S 可立即保存。
- 鼠标离开卡片与浮层时，保存后关闭。两者之间有 450 ms 移动宽限；绘制、拖动滚动条时保持浮层。保存过程中鼠标返回，会继续保留编辑状态。
- 保存失败保留浮层、错误提示和修改，可点击“重试”或按 Ctrl+S。Esc / Alt+F4 同样先尝试保存，失败不会丢弃修改。
- 右下角缩放菜单中的“适应窗口”展示完整图片，“100%”按屏幕物理像素显示；还可选择 50%、125%、150%、200%。Ctrl+滚轮连续缩放，滚动条浏览，当前比例同步显示。Alt+C 聚焦画布后，可沿用方向键、Shift 加速和 Enter 起止标注的键盘操作。

Ctrl+↑、锁屏或显示器变化会隐藏浮层，未保存修改继续等待自动保存；保存失败的修改在本次运行内保留，重新显示晾衣绳可继续处理。退出程序时若仍有未保存修改，会确认是否放弃，默认保留。

## 保存和原图

首次编辑保存会保留原图的历史记录和用于恢复的原图快照，并将当前卡片指向应用管理的 PNG 副本。后续自动保存更新这份副本，保持卡片 ID、加入时间、所在位置及数量，不反复新增卡片或历史版本。外部原文件和原有剪贴板图片文件均不会被覆盖。

编辑采用完整原图分辨率，浮层显示尺寸不会降低输出分辨率。撤销全部标注时直接恢复原图像素，避免额外渲染产生细微色差。动画图只处理首帧；输出为静态 PNG，不保留容器元数据。

保存过程检查文件是否被其他程序修改，遵守自管容量上限和使用中的文件保护。先写入并刷新暂存文件，再记录保存日志并替换副本，最后提交元数据；程序中断后可恢复已进入日志的保存。无法恢复的冲突保留文件与日志，显示错误。尚未进入保存日志的编辑草稿不保证强制结束后恢复。v0.21.1 在本次程序运行中保留最近编辑图片的逐步撤销栈，关闭浮层只释放窗口和文件使用保护；已保存的编辑历史继续保留。每张图片最多 100 步，最多缓存最近 16 张，按约 256 MiB 的图像与编辑数据预算淘汰最久未使用的记录；始终保留刚编辑的那张。图片路径、文件字节或库中内容标识变化时，丢弃不匹配的旧栈，避免把旧修改套到外部新图上。退出或重启程序会清空逐步历史，磁盘上的已保存图片和原图快照继续保留。

数据库升级到 v5，打开旧库前自动创建对应版本的数据库备份，再新增图片保存日志。数据库备份不含图片文件；升级后应继续使用 v0.21 或更新版，旧程序不能打开 v5 库。没有新增运行时依赖。

只读原图快照仍用于恢复，不直接编辑。录像不出现图片编辑工具。原有显式图片工作台入口继续保留；悬停编辑全程使用现有浮层。
