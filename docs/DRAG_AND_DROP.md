# 拖动排序与拖入图片

v0.13.1，2026-10-27。独立实现，依据用户确认的左右排序需求与 Windows/WPF 拖放机制，未参考 Windows 移植项目。

## 使用

- **排序**：展开晾衣绳，按住卡片并左右拖动，卡片跟随鼠标；插入位置两侧的照片绕夹子向外轻倾约 5°，同时让出位置。松手后平滑归位，取消则回到原顺序。多页时，在当前显示器左右边缘停留约 650 ms 翻页。卡片仍挂在绳上，不提供任意二维坐标摆放。
- **从电脑挂图**：从资源管理器选择图片，拖到已展开的卡片附近，两侧照片会向外倾斜并拉开间距；若晾衣绳收起，拖到屏幕顶部中央稍停，出现接收区后松手。空绳也可接收。一次最多 100 个文件，多张图片按拖放数据中的顺序作为一组插入。
- **拖出复制**：拖出绳子区域仍走原生 Shell 文件拖放，只允许 COPY。图片、录像原文件与卡片都保留。Esc 或目标拒收不改变排序。
- 同一文件再次拖入会移动已有卡片；从历史拖入会恢复对应记录。不同路径的图片允许同时挂上，即使像素相同。
- 新收集图片仍加在最前，其他卡片保持相对顺序。超出容量仍将最早加入的项目放进历史，排序不延长其加入时间。重新从历史挂上则按既有恢复规则重新计时。
- 左右批量取下与控制面板列表使用当前显示顺序。已有录像卡片可一起排序，外部拖入入口仅接收图片；录像继续使用目录收集或导入对话框。

图片范围沿用现有解码能力：PNG/JPEG/BMP/TIFF、GIF 首帧；WebP/HEIC/HEIF 依赖本机组件。混合拖入会忽略非图片；不展开文件夹、不接收网页图片 URL 或虚拟附件。超过 100 个文件的整个拖放会拒绝，可分批操作。损坏、失效或超限图片会反馈失败，其他有效图片继续处理。

接收区只在按住鼠标靠近时临时出现，收到有效文件拖放后才展开绳子；普通按住鼠标移动窗口经过顶部时也可能短暂看到提示，松手或移远即消失。拖拽结束恢复可选展开保护期。全屏抑制和锁屏规则继续生效。

倾斜及归位过渡约 150 ms，插入判断有 8 DIP 的缓冲，避免在两张照片分界附近反复抖动。启用“减少动画”或系统关闭动画后，保留跟随与位置反馈，停用倾斜和过渡动画。

## 实现

WPF `AllowDrop` 接收 Shell `CF_HDROP`，与已有 `SHDoDragDrop` 出站数据互通。只有允许 COPY 的拖放可被接收；不移动源文件，不使用剪贴板中转。外部图片复用文件稳定性检查、隔离解码、去重和历史流程；导入异步进行，暂停自动收集时仍可手动拖入。

临时接收窗口使用 `NOACTIVATE`，平时隐藏；插入位置与窗口布局都按物理坐标及当前 DPI 计算。内部重排先提交数据库，成功才调整卡片列表；数据库写入失败保留原显示顺序。显示顺序单独记录，不修改文件、哈希或加入时间。

绳内拖动捕获鼠标，在渲染回调中更新预览，离开绳子区域时交给原生 Shell 复制拖放。拖动期间使用同一个静止浮层和缓存的卡片快照，仅更新位移、角度；相同插入位置不会重启动画。原卡片暂时透明，导入完成、取消、隐藏、锁屏或关闭时恢复并释放捕获与动画。拖动预览期间延后库刷新，避免新收集图片打断手势。

参考：[Microsoft WPF Drag and Drop](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/drag-and-drop)、[Microsoft Shell Drag and Drop](https://github.com/MicrosoftDocs/win32/blob/docs/desktop-src/shell/dragdrop.md)、[WPF Rendering](https://learn.microsoft.com/en-us/dotnet/api/system.windows.media.compositiontarget.rendering?view=windowsdesktop-9.0)、[WPF 动画管理](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/graphics-multimedia/animation-tips-and-tricks)。

## 升级

先保存编辑并退出旧版。v0.13.1 与 v0.13.0 使用相同的 v3 库，不新增迁移。更早版本的数据库从 v1/v2 迁移到 v3，新增 `ShelfOrder` 表；首次升级先生成对应版本的数据库备份，重开不会重复备份。旧数据初始仍按原加入顺序展示。

v0.12 及更早版本不能直接打开迁移后的库。备份只包含数据库，完整回退还需要保留原图片和 Library 目录，不能覆盖正在使用的数据库。本轮测试使用生成素材与隔离数据库，未迁移用户库。

## 人工验收

- [ ] 同页左右重排时卡片跟随，两侧照片向外倾斜让位；快速反向无抖动，松手后归位，重启后顺序不变；单击、双击和长按仍按原规则工作。
- [ ] 跨页左右拖动，边缘停留时翻页，最后一页不越界。
- [ ] Explorer 拖单张、多张到展开和收起的绳子；空绳可挂上，原文件保留。
- [ ] 拖出到同盘/跨盘目录后卡片保留；Shift、Esc、移出投放区、拒收均不丢文件。
- [ ] 拖入同一图片不重复；历史图片重新挂上；损坏/混合类型/超过 100 个文件有合理反馈。
- [ ] 混合 DPI、负坐标副屏、跨屏拖动、全屏与锁屏恢复，投放区位置正确且结束后能操作下方窗口。
- [ ] 非中文长提示清晰；减少动画开关生效；提升权限的应用和普通 Explorer 之间按 Windows 权限边界实测。
