# 四种随机纸张

v0.17.0，2026-10-30。复制的文字随机使用四种纸张之一，沿用右侧文字分组和自动共享空间的布局。

| 样式 | 外观 |
| --- | --- |
| 柔黄便利贴 | 暖黄色纸面、浅色粘贴区、右下翘角、楷体风格 |
| 撕边手账纸 | 米色纸张、浅横线、页边线、下方撕边与淡绿色纸胶带 |
| 线圈笔记本 | 暖白纸页、绿色底板、蓝色横线、红色页边线与左侧线圈 |
| 极简索引卡 | 厚白纸、轻微圆角、克制的标题和分隔线 |

小卡片直接呈现纸张与文字，不再重复显示照片式边框、标题和信息栏。大小仍与图片卡片一致；取下按钮悬停出现，复制反馈短暂显示后自动隐藏。悬停全文使用同一纸张与字体，可滚动阅读；双击编辑时输入区沿用纸色和字体。

每次收集产生一个随机且持久保存的条目 ID，通过固定的 SHA-256 映射均匀分配四种样式。相邻卡片可以重复，不强制轮换；编辑、排序、分页、取下、历史恢复和重启都不会重抽。既有文字在升级后也会按原 ID 获得固定样式。数据库仍为 v4，无新迁移或外观设置开关。

纸张仅影响呈现。完整文字、复制、编辑、TXT 副本导出、容量和历史语义保持原样；纸纹、横线、胶带与装订环不进入复制或导出的文字。样式由 WPF 矢量绘制，使用系统字体回退和共享纸纹，不依赖外部图片、网络或新运行时依赖。不同系统可用字体可能略有差异。
