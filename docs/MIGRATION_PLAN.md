## 参考边界

功能基线为原版 macOS Tendedero 提交 [`32a3e47187fdea7b2fd43b3ab5a913f0ed33724a`](https://github.com/alejandrobujan/tendedero/tree/32a3e47187fdea7b2fd43b3ab5a913f0ed33724a)。后续变更单独评估，不自动扩大需求。

实现依据限定为原版 macOS 源码、确认后的需求和微软官方文档。不读取或复用现有 Windows 移植仓库来指导实现。

## 建议技术方案

- C#、.NET 10 LTS、WPF：界面、动画、设置、预览与编辑。
- Win32/COM/WinRT：托盘、剪贴板、快捷键、窗口、多屏、文件操作和媒体能力。
- SQLite：项目来源、文件归属、路径、历史状态及操作记录。
- 原文件与缩略图存于磁盘；异步解码、缩略图缓存和按需加载控制内存。
- 使用用户级存储与每用户安装，不以管理员身份作为正常运行前提。

以上技术栈已在原型中采用，完整性能与兼容性承诺以各阶段验证报告为准。

## 模块边界

| 模块 | 职责 |
|---|---|
| Core | 状态机、容量、历史、文件归属和去重策略 |
| Windows | 平台监听、显示器、全屏、快捷键、拖拽、回收站与托盘 |
| UI | 晾衣绳、卡片、设置、历史、预览、编辑 |
| Media | 解码、缩略图、图片标注导出、只读视频预览 |
| Storage | 数据库、配置、原文件、原子写入、恢复与数据迁移 |
| Tests | 核心规则、平台集成与人工验收用例 |

数据流：来源监听 → 文件稳定性/内容校验 → 去重 → 持久化 → 晾衣绳 → 使用或取下 → 历史 → 到期清理。

核心操作通过统一服务更新状态。文件操作结果成功后才能提交相应数据库状态；崩溃恢复时对未完成操作进行校验。

## 首要风险及验证方式

| 风险 | 验证或处理 |
|---|---|
| 浮层挡输入 | 浏览器、资源管理器和普通编辑器跨进程实测 |
| 拖拽保存移走原图 | 交付前仅允许 COPY；验证同盘/跨盘、Shift 请求、目标拒收与取消后原图和卡片保留 |
| 收集漏项/重复 | 文件写入稳定检测、重试、补扫、跨来源事件测试 |
| 多屏偏移 | 显式区分物理像素与逻辑坐标，测试负坐标和混合 DPI |
| 历史误删 | 按归属处理，回收失败保留，不自动永久删除 |
| 文件与数据库不一致 | 操作记录、原子替换、启动时恢复校验 |
| 透明动画资源消耗 | 隐藏后停止动画，缩略图懒加载，实测后决定模糊效果 |
