# 左右分区与笔记本卡片

v0.16.1，2026-10-29。在文字卡片需求上追加，经用户确认采用“按总容量各分一半，超出该类额度转入历史”。

## 布局与容量

- 图片、录像在左侧媒体区；文字在右侧笔记区。中间保留间隔，各区内容在自己的半区内排布，空位不借给另一类。
- 设置中的容量是总容量，每类上限为总容量的一半，奇数向下取整：25 → 各 12 项，50 → 各 25 项，100 → 各 50 项。剩余单数名额留空。
- 自动容量按当前屏幕、DPI、卡片大小及分区实际容纳量计算，使用两侧相等的名额。切换屏幕或布局容量变化时重新执行限额检查。
- 超额只取下该类按加入时间最旧的内容，进入本地历史并保留文件。拖动顺序不改变淘汰时间；恢复历史会按既有规则刷新加入时间，也只挤占同类名额。
- 升级后既有图片超过左区额度时会转入历史，仍可从历史查看、导出或重新挂上。原文件不会因为分区调整而删除。

## 交互

- 每屏每区显示数也不超过该屏总位置的一半；固定总容量大于屏幕位置数时，各区独立分页。鼠标在某区卡片上滚轮翻页，不改变另一区页码。
- 卡片只能在所属区内左右排序。拖到另一半时位置停在本区边界，不转换类型；离开绳子下方仍进入原有的副本拖出流程。
- 在本区左右边缘停留可翻页；只有本区卡片参与让位，另一区保持位置。拖入外部图片落到左侧媒体区，即使鼠标从右侧靠近，也不会混入文字。
- “取下左侧/右侧”只作用于同一区；“全部取下”仍作用于整个晾衣绳。
- 每区独立按拥挤程度堆叠、悬停突出，突出边界限制在本区。图片大图及文字全文预览沿用原规则；文字预览可滚动。

## 笔记本外观

文字卡片保留 212 × 190 DIP 的基本尺寸及三档缩放，使用暖色纸张、浅蓝横线、红色页边线、左侧装订环和较方正的纸页边框。文字摘要只用于展示，复制、编辑和导出仍交付完整文字；装饰线和装订环不进入文字内容。

外观由 WPF 矢量绘制并生成有界缩略图，无外部图像素材或新增依赖。预览与编辑功能见 [文字卡片](TEXT_CARDS.md)。
