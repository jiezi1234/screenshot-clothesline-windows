# 在悬停预览中编辑文字

v0.18.0，2026-10-30。

1. 悬停文字卡片，出现沿用该纸张样式的全文预览；仅悬停不会抢走当前应用的键盘焦点。
2. 点击浮层底部的“编辑文字”，直接在原浮层中输入、换行、选中、粘贴、撤销或重做。四种纸张都支持长文滚动。
3. 点击“保存文字”或按 Ctrl+S 更新原卡片。内容、标题和缩略图随后刷新，样式、顺序与加入时间保持不变。
4. “取消编辑”放弃本次修改，恢复原文。Esc、Alt+F4 或退出程序时，若有未保存修改会询问是否放弃；默认保留草稿。保存进行中不能重复提交或放弃。

编辑时浮层保持打开，鼠标移开不会丢失草稿。Ctrl+↑ 收起、锁屏或显示器变化会隐藏浮层，草稿和文件使用保护仍保留；再次显示晾衣绳时恢复编辑浮层。编辑结束后恢复普通悬停预览；如果键盘焦点仍在浮层内，则归还给编辑前的窗口，不干扰用户已经切换到的其他应用。

编辑期间暂停晾衣绳的刷新、排序和外部图片拖入，结束编辑后恢复。后台收集可继续，待浮层编辑结束后显示新增卡片。双击和历史里的原独立编辑器入口保留；同一条文字已经在一个编辑入口打开时，会回到现有编辑界面。

复用原有文字保存事务、内容校验、配额和冲突检查。文件被外部修改、锁定、内容无效或保存失败时，保留当前草稿与原文件；不会自动覆盖外部修改。浮层中的复制和剪切沿用自身剪贴板标记，避免重复收集。草稿仅在本次运行中保留，不提供断电或强制结束进程后的未保存草稿恢复。
