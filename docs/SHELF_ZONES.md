# 共享空间与笔记本卡片

v0.16.2，2026-10-29。图片和录像靠左，文字靠右，两类内容按数量自动适配整条绳子的空间。

## 布局与容量

- 媒体从左边排列，文字从右边排列。数量较多的一类可越过屏幕中线，只有一种内容时可使用整条绳子。
- 内容较少时保留正常间距与中间空白；拥挤时缩短间距，最多重叠卡片宽度的 40%。悬停后卡片突出，继续停留显示完整预览。
- 容量按所有类型合计：25 可放满 25 项，50 可放满 50 项，100 可放满 100 项。自动容量按当前屏幕、DPI、卡片大小和整排可见位置计算；屏幕或大小改变时重新检查。
- 超额时按加入时间将全体最旧的项目转入历史，保留文件。排序不改变淘汰时间；恢复历史刷新加入时间，可能将另一类型的最旧项目挤入历史。
- 旧版本已转入历史的内容保留原状态，可手动重新挂上；本次更新不会自动恢复历史条目。

## 交互

- 固定容量超过当前屏幕的可见位置数时，按两类数量比例分配每屏名额；两类都有内容时均保留可见入口，各自独立分页。
- 最后一页按实际剩余项数重新排布，媒体仍靠左、文字仍靠右；鼠标在卡片上滚轮只翻动这一类型的页码。空间变化时两类卡片位置可能一起调整。
- 同一类型内拖动排序并持久保存。拖动中的卡片可跟随鼠标越过中线，落下时仍保持媒体在前、文字在后的分组顺序；离开绳子下方继续使用副本拖出流程。
- 拖动时在屏幕左右边缘停留可以翻页；相邻同类卡片倾斜让位。外部图片拖入后加入媒体组，原文件保留。
- “取下左侧/右侧”作用于同一类型；“全部取下”作用于整个晾衣绳。
- 图片大图及文字全文预览沿用原规则；文字预览可以滚动，单击复制完整文字，双击在应用内编辑原卡片。

## 文字卡片外观

文字卡片保留 212 × 190 DIP 的基本尺寸及三档缩放。v0.17.0 起随机呈现便利贴、手账纸、线圈笔记本、索引卡四种固定样式，细节见[纸张外观](TEXT_PAPER_STYLES.md)。文字摘要只用于展示，复制、编辑和导出仍交付完整文字；装饰线和装订环不进入文字内容。

外观由 WPF 矢量绘制并生成有界缩略图，无外部图像素材或新增依赖。预览与编辑功能见 [文字卡片](TEXT_CARDS.md)。

## 待人工体验

- [ ] 图片多、文字少时，图片可越过中线；反过来文字可向左展开。
- [ ] 只有图片或只有文字时可使用整排位置；数量少时分别靠左、靠右。
- [ ] 容量设为 25，合计第 26 项使最旧项进入历史，文件仍保留；单一类型也能放满 25 项。
- [ ] 两类分别排序和翻页，末页少量文字仍靠右；拖出保存副本后原卡片保留。
- [ ] 从资源管理器拖入图片，图片进入媒体组并自动调整间距。
- [ ] 拥挤、三档大小、混合 DPI、锁屏恢复、减少动画下，悬停突出与预览正常。

数据库仍为 v4，不新增迁移、设置开关或快捷键；各类型内的既有顺序保留。旧版数据库兼容性说明见 [文字卡片升级说明](TEXT_CARDS.md#升级)。
