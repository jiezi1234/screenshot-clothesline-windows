# Windows 截图晾衣绳需求规格

状态：需求草案；已确认项与建议值分别标明。更新日期：2026-10-22。

## 已确认的决定

1. 首发目标为 Windows 11 x64。
2. 原版 macOS Tendedero 是功能参考；不参考或复用已有 Windows 移植项目。
3. 超过容量时只将项目移出晾衣绳并转入本地历史，文件由独立的历史清理策略管理。
4. 独立维护公共 GitHub 仓库。
5. 拖拽保存后，原图片和卡片继续留在晾衣绳上；拖出统一提供副本。

## 产品目标

保留用户的 Windows 截图习惯，让图片自动进入顶部晾衣绳，完成复制、预览、编辑、拖出、取下和找回历史的流程。

初期范围不包含云同步、账号、OCR、AI、文字便签或自建完整截图引擎。截图标注和录像裁剪属于完整迁移范围，分阶段实现。

## Windows 交互约定

- 日常浮层不抢键盘焦点；预览、编辑和键盘操作由用户主动进入。
- 卡片外的空白区域能操作下方应用；隐藏后不留下拦截输入的透明窗口。
- 顶部触发区避开左右角的窗口控件；拖拽和菜单操作期间保持展开。
- 单击等待系统双击判定，避免双击打开时顺带改写剪贴板。
- 不以剪贴板格式承诺准确识别截图来源；界面使用“收集剪贴板图片”等准确文案。
- 不自动改写 Windows 截图工具的保存路径或通知设置。
- 没有可靠截图区域信息时使用固定入场动画，不猜测真实截图位置。
- 拖拽在交付前只声明复制权限，不提供移动权限；同盘、跨盘均保留原图与卡片。目标返回移动结果时也不授权删除。Shift 或回收站等需要移动权限的目标可能拒收；删除通过右键回收站执行。
- 快捷键冲突时提示并保留旧设置；不得抢占其他应用已经注册的全局快捷键。
- 简体中文与英文优先；其他原版语言在完整迁移阶段逐步补齐。

## 文件生命周期

所有记录标记来源及归属：`Managed`（应用创建）或 `External`（外部目录引用）。

| 操作 | Managed | External |
|---|---|---|
| 挂上 | 管理应用创建的文件 | 引用现有文件，默认不复制 |
| 拖出保存 | 向目标交付副本，原图和卡片保留 | 向目标交付副本，原图和卡片保留 |
| 关闭、批量取下、超容量 | 转入历史，文件保留 | 转入历史，原文件保留 |
| 历史到期 | 文件移入回收站后移除记录 | 仅移除记录 |
| 明确选择删除文件 | 成功移入回收站后更新记录 | 成功移入回收站后更新记录 |
| 编辑 | 产生编辑结果并保留可恢复原版 | 默认生成副本，不覆盖来源文件 |
| 原文件失效 | 标记失效并提供移除记录入口 | 标记失效，说明依赖原路径 |

- 历史期限按“取下时间”计算；仍在晾衣绳上的项目不参与历史到期清理。
- 编辑原版、副本与缩略图均需纳入关联清理，避免遗留文件。
- 回收站操作失败不转为永久删除，保留记录并报告原因。
- 文件导出、编辑、删除期间不得被后台清理。
- 存储上限到达时暂停新增自管文件；不自动清理外部文件。
- 重新挂上会取消当前历史到期计时，再次取下后重新计时。
- 本地历史仅用于暂存；外部引用失效后不能保证找回原文件。

## 媒体支持范围

- 首先保证 PNG、JPEG、BMP、TIFF 和 GIF 首帧。
- WebP、HEIC 通过解码器兼容性验证后加入；缺少支持时明确提示，不静默下载解码器。
- 视频先验证 MP4 的具体编码组合，再扩展 MOV；容器扩展名不代表所有编码都可播放。
- 视频裁剪不预先承诺所有格式无损；输出成功并验证后再更新记录。
- 图片在内存中优先使用缩略图，原图按需加载；异常大图、损坏文件应可跳过并给出反馈。

## 验收标准

- 连续 100 张测试截图最终收集完整，同次截图的文件/剪贴板双来源不重复挂上。
- 单击、双击、长按、拖拽互不误触；取消拖拽不丢文件。
- 资源管理器、浏览器上传框、Office 和用户实际使用的聊天软件分别验证。
- 外部文件不会因为取下、超容量或历史到期而被删除。
- 重启、异常退出、休眠恢复后能校验并恢复列表与文件状态。
- 多屏 100%/150%/200% 缩放、负坐标、拔插、主屏变化通过验收。
- 普通最大化、全屏视频/游戏、屏幕共享分别验证。
- 隐藏时平均 CPU 低于 0.5%、普通图片可读取后约 500 ms 内挂上，作为固定测试设备上的初始目标；原型后调整并记录测量方法。
- 首要本机测试环境：Windows 11 23H2 x64；发布前增加当前受支持 Windows 11 版本的干净环境验证。
